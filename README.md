# Keyboard Test Pro replacement files

Upload the files in this folder to the root of the existing `KeyboardtestPro` GitHub repository, replacing matching website files. Keep existing Vercel configuration files that are not included here.

- Homepage includes an interactive keyboard tester and responsive layouts.
- Links to Mic Test Pro, Screen Test Pro, and NetSetGo Pro are included in the main page and footer.
- About, Privacy Policy, Terms, and Contact pages are included.
- AdSense loader and `ads.txt` publisher record are retained; no ad slots are enabled. AdSense approval remains pending.
- Vercel Analytics script is included.

After committing, wait for the Vercel deployment to finish and test keyboard input on desktop and mobile with a connected physical keyboard. Browser shortcuts and some function keys may not be detectable.
