How to test your keyboard

  1. Choose the layout closest to your keyboard.
  2. Press keys one by one. Detected keys turn green.
  3. Check whether any key fails to highlight or repeats unexpectedly.
  4. Use Reset test to start again.

For laptop keyboards, function keys and special media keys may be intercepted by your operating system and may not appear in the test.

Keyboard testing FAQ

Why is a key not detected?

Browser shortcuts, operating-system hotkeys, or certain keyboard drivers can prevent some keys from reaching a webpage. Try another browser and check the key in another application.

Can this fix a broken key?

No. This tool helps identify keys that may be faulty; it does not repair hardware or change keyboard settings.

Does it record what I type?

This page highlights detected key names for the test. Avoid typing passwords or other sensitive information while testing.

Does it work on mobile?

The page adapts to small screens, but testing a physical keyboard requires connecting one. The on-screen mobile keyboard may not send all key events to a webpage.
